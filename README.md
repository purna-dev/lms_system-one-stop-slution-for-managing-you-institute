# Institute LMS (`app_q`)

All-in-one institute toolkit — React + Vite + localStorage.

## Run

```bash
npm install
npm run dev
```

## Demo logins

## Modules

Dashboard · Calendar · Timetable builder · Students · Batches · Attendance · Payments  
Exams & gradebook · Assignments · Admissions pipeline · Notices · Reports + CSV · Teachers  
Parent portal · Command palette (`Ctrl+K`) · Themes · Audit log

## Tip

After upgrades, use **Settings → Reset demo data** (or clear `lms.*` keys) if schema bumped.
